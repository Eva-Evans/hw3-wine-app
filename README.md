# Подборка хороших вин

Приложение показывает, попадёт ли вино в подборку сервиса. Модель уже обучена и лежит в `model.joblib`. Внутри приложения она не обучается.

Проверено на Python 3.14.2.

## Как запустить

Из корня репозитория, в уже созданном окружении:

```bash
source .venv/bin/activate
cd homework/hw_3/wine_app
streamlit run app.py
```

Либо из этой папки в новом окружении:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Откроется страница в браузере. Порог по умолчанию читается из `config.json`.

## Кэш

Для модели используется `st.cache_resource`, для таблицы `test.csv` и вероятностей на ней — `st.cache_data`.

`st.cache_resource` отдаёт один и тот же объект всем вызовам и всем сессиям. Так и нужно модели: копия логистической регрессии заново собирала бы её из байтов. `st.cache_data` кэширует обычные данные и на каждый вызов отдаёт копию, чтобы одна сессия не испортила таблицу другой.

Если вызвать `joblib.load` без декоратора, скрипт при каждом движении ползунка снова прочитает `model.joblib` с диска. Вероятности на тесте от порога не зависят, поэтому это лишняя работа. Загрузка модели через `st.cache_data` тоже не подходит: этот декоратор возвращает копию, а не тот же объект.

## Деплой на Streamlit Community Cloud

1. Залейте папку `wine_app` в репозиторий на GitHub. В ней должны лежать `app.py`, `model.joblib`, `config.json`, `test.csv`, `requirements.txt` и этот файл.
2. На [share.streamlit.io](https://share.streamlit.io) выберите репозиторий.
3. Если в репозитории весь курс, укажите главный файл `homework/hw_3/wine_app/app.py`. Если репозиторий состоит только из этой папки, главный файл — `app.py`.
4. Версия Python — 3.14. Пакеты ставятся из `requirements.txt`.
